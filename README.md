# 🚀 Crypto Alert Bot

A Python-based Telegram crypto alert bot that tracks live cryptocurrency prices using the CoinGecko API and sends instant alerts directly to Telegram.

---

## ✨ Features

- 📈 Live crypto price tracking
- 📲 Telegram alert notifications
- 🔄 Auto-refresh every 60 seconds
- 🛡️ Error handling & retry system
- ⚡ Lightweight and beginner-friendly

---

## 🪙 Supported Coins

- Bitcoin
- Ethereum
- Dogecoin

You can easily add more coins inside the code.

---

## 🛠️ Technologies Used

- Python
- Requests
- Telegram Bot API
- CoinGecko API
